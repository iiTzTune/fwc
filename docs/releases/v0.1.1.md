# Field Wireless Companion v0.1.1

This release adds the plugin permission contract and the first observation
plugins on top of v0.1.0. Plugins now declare permissions — `radio.tx`,
`radio.raw`, and `radio.config` — and the core rejects ungranted commands with
a typed `permission_denied` error before any radio state changes. The capture
worker owns a receive-only radio control surface: channel changes and dwell
adjustments. Frame transmission remains a reserved seam behind `radio.raw`.

Shipped plugins: `fwc-plugin-hop` (channel cycling reference), `pcap-sink`
(raw frame retention with download), `geo-log` (GPS tagging and offline map),
`peers-mesh` (versioned peer wire format with test vectors), `export-web`
(HMAC-SHA256-signed observation summaries), `stats-faces` (epoch scores on the
companion display), and `smart-sweep` (dwell adapted to observed client
density).

## Download and verify

`fwc-x86_64.img.zst` contains the full disk image for 64-bit UEFI. Use it for
a fresh installation. `fwc-slot.ext4.zst` contains one OS slot for an existing
device. Both artifacts are covered by the signed `SHA256SUMS` manifest.
The release signing identity is `fwc-release`; verify its public key fingerprint
with a trusted copy before checking signatures.

```text
SHA256:Fuv3LdOFYESNny6xWVxg4w8P9KfqZSOl9selZPkfKVM
```

From a new download directory with GitHub CLI, OpenSSH, zstd and sha256sum,
fetch the release assets. Check the fingerprint of the key in the allowed
signers file and verify the checksum manifest before opening either image.

```sh
gh release download v0.1.1 --repo iiTzTune/fwc
awk '{print $3, $4}' release-signers | ssh-keygen -lf -
ssh-keygen -Y verify -f release-signers -I fwc-release -n fwc-image -s SHA256SUMS.sig < SHA256SUMS
sha256sum --check --ignore-missing SHA256SUMS
zstd -dk fwc-x86_64.img.zst fwc-slot.ext4.zst
sha256sum --check SHA256SUMS
```

To verify the signed source tag, use the same trusted signer file in a
checkout of the project.

```sh
git fetch origin tag v0.1.1
git -c gpg.format=ssh -c gpg.ssh.allowedSignersFile="$PWD/docs/release-signers" verify-tag v0.1.1
```

## Plugin permissions

Installed plugins list their requested permissions in the settings page, where
each grant can be revoked individually. A revoked grant stops the plugin with a
typed error and leaves capture continuity untouched. `radio.raw` is reserved:
the frame-transmission seam is documented in the plugin author guide and no
shipped plugin uses it yet.
