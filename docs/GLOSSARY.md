# FWC Glossary and Vocabulary Rules

Use these terms in code, comments, and docs. Do not use security-flavored wording.

## Use
- observation session — a period of active monitoring
- activity log — the durable record of observed events
- network record — one visible network's entry
- association event — a device joining or leaving a visible network
- monitor-mode capture worker — the process managing the radio interface
- channel scanner — channel-cycling logic
- companion display / device face — the on-device screen UI
- peer — another FWC-class device observed nearby
- slot — a complete bootable OS image copy on its own partition

## Avoid
- pwn, handshake harvest, attack, crack, deauth, injection, exploit, pentest, Kali
